# v0.3.1 Calibration Report — Political Dynamics

> 项目计划书 v0.3.1 §46。模型校准（Model Calibration），非功能扩展。

## 1. v0.3 异常现象

长跑稳定复现：

```
1. Agent 周期性向 X 轴两端聚集
2. X 轴形成双峰/两极
3. Y 轴变化显著弱于 X
4. Z 轴持续向 Z+（个人主义）漂移
5. 长期压缩为：X 两极 + Y 近中心 + Z 偏正
```

## 2. 根因（代码路径，见 docs/political_dynamics_v0.3.1_audit.md）

### 2.1 X 二值分叉

```python
# v0.3 economic_force_x / interpret_event
econ_dir = -1.0 if gov >= 0.5 else 1.0    # ← gov 被压缩成 {+1,−1}
```

连续人格变量 `gov = (trust + authority_preference) / 2` 被二值分类器压缩，
`gov=0.49` 与 `gov=0.51` 产生完全相反且量级相同的力，天然制造双峰。

### 2.2 Z 永久 Z+

```python
# v0.3 community_force_z
((1.0 - isolation) * 0.5 - isolation * empathy)
```

`(1.0 - isolation) * 0.5` 恒 ≥ 0（联结良好 → +0.5），默认网络下多数 Agent
联结良好，力 ≈ +0.5，无论人格/事件/资源都持续向 Z+ 漂移。

### 2.3 Y 弱动力

```python
# v0.3 authority_force_y
legitimacy_stress = 0.5 - trust_gov
fy = legitimacy_stress * (authority - 0.5) * 2.0 * 0.03
```

唯一驱动是 `trust_in_government`，强度 0.03，被 anchor(0.02) + center(0.005)
+ 信任惯性平滑压制。

## 3. 修改前后的公式

| 轴 | v0.3（旧） | v0.3.1（新） |
|---|---|---|
| X | `pressure * 0.4 * (-1 if gov≥0.5 else +1) * wx` | `tanh(pressure·sat) * economic_strength * econ_bias * wx`，`econ_bias = tanh((0.5−gov)·sensitivity)` + deadzone |
| Y | `(0.5−trust_gov) * (authority−0.5)*2 * 0.03 * wy` | `(legitimacy_stress·authority_strength + security·security_strength + institutional·legitimacy_strength) * (authority−0.5)*2 * wy` |
| Z | `((1−isolation)*0.5 − isolation*empathy) * 0.02 * wz` | `(autonomy_pref·autonomy_strength − belonging_need·belonging_strength) * (1 + group_pressure·connectedness) * wz` + 邻居 Z 顺从 |
| Z 事件 | `sz * −(empathy−0.5)*2` | `sz * (autonomy_pref − belonging_need)`（双向，非硬 empathy 映射） |
| 耦合 | `C × velocity` | `mode ∈ {velocity, state, hybrid}`（§22） |

其中派生人格（§9）：

```
autonomy_pref = (openness + risk_tolerance + (1 − agreeableness)) / 3
belonging_need = (agreeableness + empathy + extraversion) / 3
```

## 6. 长跑校准矩阵（§35, §36, §42）

### 6.1 Baseline（1000 Agent × 100 天，seed 42）

| 指标 | X | Y | Z |
|---|---|---|---|
| 均值（终） | -0.057 | -0.021 | 0.027 |
| 漂移（/tick） | ~0.00000 | — | ~-0.00000 |
| 方差 | 0.139 | **0.213** | 0.077 |
| 极化 | 0.65 | **0.80** | 0.48 |
| 分布形态 | **single_peak** | uniform | single_peak |
| 边界集中 | X− 0% / X+ 0% | Y− 0% / Y+ 0% | Z− 0% / Z+ 0% |

相关性：xy=0.22 / xz=0.38 / yz=−0.38（弱耦合，未同步）。主导轴（force）：Y_DOMINANT。

**对照 v0.3 异常**：X 双峰 → 单峰 ✅；Z+ 漂移 → ≈0 ✅；Y 静止 → 最强轴 ✅；边界塌缩 → 0% ✅。

### 6.2 力预算（中性条件，人口平均占比）

| 来源 | X | Z |
|---|---|---|
| economic / community | <3% | 33.8% |
| social | 6.0% | 11.2% |
| anchor | 40.7% | 30.1% |
| center | 36.4% | 15.6% |
| noise | 11.0% | 6.8% |

⚠️ 中性条件下 X 的经济力 <3%，anchor+center 占 ~77%——符合「无压力时 X 稳定」，
但 anchor 占比偏高，§25 要求确认其非「万能反向力」（见 §8 剩余问题）。

### 6.3 场景矩阵（1000 Agent × 100 天 × 3 seeds，`scripts/calibrate.py`）

| Scenario | X Drift | Y Drift | Z Drift | X Var | Y Var | Z Var | X Pol | Y Pol | Z Pol |
|---|---|---|---|---|---|---|---|---|---|
| baseline | 0.00000 | -0.00000 | -0.00000 | 0.226 | 0.158 | 0.106 | 0.81 | 0.69 | 0.56 |
| no_events | 0.00000 | -0.00000 | -0.00000 | 0.139 | 0.152 | 0.080 | 0.65 | 0.68 | 0.49 |
| no_social | 0.00000 | -0.00000 | -0.00000 | 0.198 | 0.165 | 0.149 | 0.76 | 0.70 | 0.65 |
| **no_anchor** | 0.00000 | -0.00001 | -0.00001 | 0.122 | **0.016** | 0.118 | 0.50 | **0.18** | 0.55 |
| no_coupling | 0.00000 | -0.00000 | -0.00000 | 0.226 | 0.158 | 0.106 | 0.81 | 0.69 | 0.56 |

**结论**：

1. **所有场景 drift ≈ 0** —— 无系统性 X/Y/Z 漂移，X 二值塌缩与 Z+ 单向漂移均已消除。
2. **no_coupling ≈ baseline**（三位小数相同）—— 耦合是弱耦合，不影响结果（§23 ✅）。
3. **no_events 方差略降**（X 0.226→0.139）—— 事件贡献部分多样性，但非主要来源。
4. **no_anchor → Y 方差塌缩 0.158→0.016** —— anchor 是 Y 轴多样性的主要来源。
   ⚠️ 这是 §25 的警示：Y 动力尚不能自持，依赖 anchor 充当「反向力」。需在后续版本
   强化 Y 的内生驱动（制度绩效反馈、群体形成），而非调大 anchor。

## 8. 剩余问题

1. **长跑是缩水版**：计划书要求 1000×1000 天×10 seeds，纯 Python ~50 ticks/sec
   下约需数十小时；本次跑 100 天×3 seeds 作演示（`scripts/calibrate.py` 参数可调）。
2. **Y 轴依赖 anchor 维持多样性**：no_anchor 场景 Y 方差塌缩 0.158→0.016（§25 警示
   已证实）。Y 的内生驱动（制度绩效反馈、群体形成）需强化，而非调大 anchor。
3. **社会网络仍静态**：群体形成/就业/贸易/政党（Phase 8）未实现，Z/Y 的内生
   驱动仍受限于固定拓扑。
4. **实验模式（§40 `POST /api/experiment/calibrate`）** 未实现；诊断 API（§39）与
   UI 诊断面板（§29）已完成。
